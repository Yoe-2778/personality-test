# 亲密来信 · 我的亲密关系使用说明书

第一版：以白灰小猫与灰色小猫为主角的中文关系偏好测试网页。使用原生 HTML、CSS 和 JavaScript，无需安装运行依赖。

当前品牌为「亲密来信 / CLOSER NOTES」，适用于伴侣、挚友等重要关系。首页、题目、结果及下载卡片采用一致的包容性文案。题序与评分方向保留，因此旧版浏览器进度仍可继续使用。

16 种画像现在使用小猫昵称：暖暖猫、蹦蹦猫、悄悄猫、月亮猫、窝窝猫、叮当猫、栗栗猫、糯糯猫、直直猫、风风猫、慢慢猫、星星猫、稳稳猫、溜溜猫、苔苔猫、云云猫。首页和导航可打开「小猫关系图鉴」，也可直接访问 `/#cats`；卡片展示四个偏好，支持按靠近节奏筛选，并可打开 `/#cat-1` 至 `/#cat-16` 的画像示例。浏览图鉴不修改答题进度、不增加生成次数。结果、复制内容和分享图片均使用新昵称。

图鉴的 16 张插画各自独立生成，分别呈现两只小猫喝茶、吹泡泡、写信、搭窝、放风筝、观星等不同活动，不再重复使用同一场景。网页素材位于 `assets/cats/gallery/`，提示词与原图位于 `assets/cat-reference/gallery-v1/`，来源和处理方式详见该资源目录的 README。

画像名字与图片固定对应：真实结果、图鉴示例、结果页分享预览、分享编辑窗口与下载 PNG 均按同一类型编号使用图鉴插画。

首页、页头和第一张维度卡的小猫插画已恢复第一版，保留「亲密来信」品牌和兼顾友情的文案。后续生成的表情修订素材保留供对照，正式页面不引用。

## 本地运行

需要 Node.js 20 或更高版本。在项目目录执行：

```sh
node server.mjs
```

打开 http://127.0.0.1:3000 。如需其他端口，设置 `PORT` 环境变量。服务器默认只监听本机。

手机在同一 Wi-Fi 下测试时，可用 PowerShell 另开局域网预览服务：

```powershell
$env:HOST = '0.0.0.0'
$env:PORT = '3001'
node server.mjs
```

在手机浏览器打开 `http://电脑的局域网IPv4地址:3001/`。电脑需保持开机且服务持续运行。原有本机 3000 端口预览可继续使用。

## 已包含

- 24 道原创生活情境题，四个维度各六题，各含三道反向题。
- 单题选择、上一题、键盘选项操作、修改答案与重新开始。
- 浏览器本地保存与恢复进度，可在隐私说明中清除。
- 小猫读信后靠近的进度：白灰小猫捡到信，读懂灰猫的委屈，每完成一道新题便走近一格，共 24 格，最终在结果页拥抱。修改已答题不重复计步，刷新后按已完成题数恢复位置，并支持减少动态效果。
- 16 种关系画像、四维偏好坐标、分维度相处建议与自我练习。
- 中间区间使用兼有两种偏好的文案，避免把微弱差异过度解释。
- 结果示例、可编辑的 PNG 分享卡片、复制相处提示。
- 分享按钮下显示「已测试小咪：X 只」；每次点击「生成我的说明书」加一，即使答案未改动也计数。修改后重新生成同样加一，预览示例、刷新和重新查看已有结果不计数。次数保存在当前浏览器，重新测试时保留，清除本地测试数据时归零。
- 桌面与手机布局、减少动态效果支持、键盘焦点与原生对话框。
- 已选定的手绘双猫主题：品牌标识、首页、四维介绍、答题陪伴、结果说明和下载卡片。
- 首页白猫的泪滴使用独立 SVG 图层，从眼角错开向下滑落、加速并淡出；随主图同比例缩放，减少动态效果模式下显示静态泪滴。
- 下载卡片支持称呼与最多160字提示，长文案自动调整字号与画布高度。

## 双猫主题资源

正式页面使用 `assets/cats/` 中的优化素材与 `cats.css`，全部随项目提供，无需生成图片即可运行。

素材基于用户提供的两只小猫参考图延展，来源、参考副本与生成提示保存在 `assets/cat-reference/`。

`scripts/prepare-cat-assets.py` 可从已经生成的素材重建网页资源（仅重建素材时需要 Python 和 Pillow）：裁切首页主图，移除与画面边缘连通的浅色纸张背景并保留白猫内部，缩放小场景与图标。

主入口 `/` 是可完整体验的正式第一版；`/cat-reference.html` 与 `/cat-concepts.html` 保留为历史视觉方案供对照。

## 内容与隐私

题目、画像、评分函数位于 `data.js`。每题四个选项的原始分依次为 3、1、-1、-3，乘题目方向后累计。每维范围为 -18 到 18，换算为位置坐标。绝对累计分小于等于 4 时显示兼有两种偏好；类型名称由各维相对方向组合，仅作为阅读入口。

应用不上传答案或结果，无账号和追踪统计。进度与生成次数保存在浏览器 `localStorage`，下载卡片由 Canvas 在本地生成。字体使用 Google Fonts 的思源宋体，无法访问字体服务时使用系统字体；其请求不包含答题数据。

本项目为原创自我探索工具，未经心理测量学验证，不应用于心理诊断、人格定论或关系匹配预测。

## 验证

```sh
node --test tests/*.test.mjs
```

服务启动后可检查：完成测试 → 查看结果 → 修改答案 → 重新生成 → 编辑并下载卡片。刷新页面后从首页恢复进度；隐私说明内可清除数据。

完整浏览器检查脚本为 `tests/browser-check.mjs`，需要本机 Chrome 和可选的 Playwright 测试依赖。在启动服务后执行：

```sh
npm install --no-save --package-lock=false playwright
node tests/browser-check.mjs
node tests/journey-check.mjs
node tests/count-check.mjs
node tests/hero-tears-check.mjs
```

截图与下载卡片输出到 `test-results/`，不纳入版本控制。

## GitHub Pages 子目录部署

正式入口为 `index.html`。页面、脚本和两个历史参考页使用相对资源路径，可放在站点根目录或 `/cati/` 等仓库子目录。图鉴通过 `#cats` 和 `#cat-1` 至 `#cat-16` 切换，刷新不需要服务端路由。

无需构建或部署 `server.mjs`；它仅用于本地预览。静态发布内容为 `index.html`、`app.js`、`data.js`、`styles.css`、`cats.css`、`gallery.css`、`assets/` 和 `.nojekyll`，如需保留历史参考页，再包含 `cat-reference.html` 和 `cat-concepts.html`。测试、生成脚本和 `node_modules/` 不需要发布。

本地模拟 GitHub Pages 的 `/cati/` 子目录（需要已安装的 Playwright 和 Chrome）：

```sh
node tests/pages-check.mjs
```

该命令只启动临时本机静态测试服务，检查全部资源、参考页面、图鉴、答题、报告、分享下载与动画，并自动关闭服务。现有单项浏览器测试也可通过 `TEST_BASE_URL` 指向其他静态预览地址。答题进度与生成次数仍保存在各自浏览器；字体无法连接 Google Fonts 时使用系统字体。
